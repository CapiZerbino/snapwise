Snapwise is a native macOS menu-bar app for screenshots, screen recordings, annotation, OCR and window snapping — free and open source.

Download for macOS View source

macOS 15 or later · Apple silicon and Intel · MIT license

Everything in one menu-bar app

Written in Swift with ScreenCaptureKit, AVFoundation and Vision. No third-party dependencies, no account, nothing leaves your Mac.

Capture

Screenshots

Area, window, full screen, previous area, self-timer and an All-In-One mode. Crosshair, magnifier, frozen screen, and window shots on wallpaper, solid or gradient backgrounds.

Capture

Scrolling capture

Stitch long pages vertically or horizontally, by hand or with auto-scroll. Sticky headers and footers are kept once.

Capture

Text recognition

Select any area to copy its text. On-device OCR with automatic language detection; also reads QR codes and barcodes.

Record

Video and GIF

Record an area, window or the full screen as MP4 or GIF with computer audio, microphone, pause, click highlights, keystroke display and a camera bubble.

Record

Video editor

Trim, switch between landscape, square and vertical canvases, add gradient backgrounds, auto-zoom on recorded clicks, export to MP4 or GIF.

Edit

Annotate

Arrows, shapes, pencil, highlighter, text, counters, blur, spotlight, crop, rotate and a background tool with gradients, padding and shadows. Editable project files.

Workflow

Quick access overlay

Every capture lands in a thumbnail stack: copy, save, annotate, pin, or drag it straight into another app.

Workflow

Pin and history

Float a screenshot above all windows with adjustable size and opacity. Browse, restore and re-export past captures from the history.

Windows

Window snapping

Drag to an edge or corner for halves, quarters and maximize with a live preview, or use shortcuts for thirds and two-thirds. Custom snap areas, title-bar button actions, modifier move and resize.

Install

Snapwise is signed but not notarized by Apple, so the first launch needs one extra step.

  1. Download the zip from the latest release, unzip it and move Snapwise.app to Applications.
  2. Open it. If macOS blocks the app, go to System Settings › Privacy & Security and choose Open Anyway.
  3. Grant Screen & System Audio Recording when asked, then relaunch. Window snapping also needs Accessibility.
  4. Prefer building it yourself? Clone the repo, brew install xcodegen, then run ./build.sh Release.
