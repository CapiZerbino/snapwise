Install

Up and running in a minute

Snapwise is signed but not notarized by Apple, so the first launch needs one extra step.

  1. Download and move. Get the zip from the latest release, unzip it and move Snapwise.app to Applications.
  2. Open it. If macOS blocks the app, go to System Settings › Privacy & Security and choose Open Anyway.
  3. Grant access. Allow Screen & System Audio Recording, then relaunch. Window snapping also needs Accessibility.

Prefer building it yourself? Clone the repo, brew install xcodegen, then run ./build.sh Release.
